# pi-compact-tool-calls

Compact Pi tool-call rendering with rich Bash, Python, image, and diff panels.

## Install

```bash
pi install git:github.com/yippiez/pi-compact-tool-calls
```

For a project-local installation:

```bash
pi install -l git:github.com/yippiez/pi-compact-tool-calls
```

## Development

```bash
npm install
npm run typecheck
pi --no-extensions -e .
```

Extracted from the current implementation in [pchain](https://github.com/yippiez/pchain).
